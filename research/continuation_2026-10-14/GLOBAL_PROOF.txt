1. 定理及其边界

沿用 ../../3sum_certificate_1p960614_v3/3sum_certificate_v3/PROOF.md
第 7 节的模型：每个算法使用一个固定整数 c>=3；成本是该文件第 1 节
十二项的最大值 R；参数满足 e>0、b<0、S>0、0<=theta<=1/2、
v=S-2b>0、gamma_c(theta)>=v、rho>=max H(t)/(1+gamma_c(t))。
保留原模型的其他可行性条件。所有符号与原文件一致。

本轮证明：

  对每个整数 c>=3 且 c!=232，每一组容许参数都有
      R > 1.960613492。

  c=232 已有可行证书的最大成本是
      1.960613491898215639207424 < 1.960613492。

因此 c=232 是这个模型唯一可能达到整体最优下确界的整数扩张选择，且

  1.96061349120 < inf_{integer c>=3} R_model(c) < 1.960613492。

更精确的全域下界沿用 c=232 的证书：
  R >= 1.960613491206699282734344...

这补上 v3 未处理的“其他整数 c”空缺。不是 3SUM 的复杂度下界，
不排除混合 c、各层不同 c、非整数平均扩张、非统一熵计费或新算法。
也不证明修改后完整 word-RAM 算法达到该指数。

2. 三条关于 c 的单调性

令 F(c,x)=c H(x/c)，H 是二元熵（以 2 为底）。固定 x，微分得

  partial_c F(c,x) = -log_2(1-x/c)。

因而，对实数 c>=3（此处只是辅助估计），

  E_c' = -(1/2)log_2(1-1/c) > 0；

  kappa_c' = log_2[(1-1/c)/(1-1/(2c))^2] < 0；

  partial_c gamma_c(t)
    = log_2[(1-(1-t)/c)/(1-1/c)] >= 0。

第二个严格不等式使用
  (1-1/(2c))^2 = 1-1/c+1/(4c^2) > 1-1/c。
第三个在 t>0 时严格。二元熵在 [0,1/2] 上递增；gamma 对 t 也递增。

3. 一次验证整个区间 [l,h]

任选 3<=l<=h 和有理点 u,t0 in (0,1/2)。对所有 c in [l,h]，取

  E0 <= E_l <= E_c；
  k0 <= kappa_h <= kappa_c；
  rho0 <= H(u)/(1+gamma_h(u)) <= rho_c^*；
  g0 >= gamma_h(t0) >= gamma_c(t0)；
  h0 <= H(t0)。

检查器对上述五个值使用精确 Fraction 对数区间，并向外取 21 位小数，
故端点小数全部是有理数，不依赖机器浮点。

若 rho0>=1/2，递归报告的节省系数满足

  1/2-kappa_c-rho +(2rho-1)b-rho*S < 0，

因为 b<0、S>0、rho>=rho0、kappa_c>=k0>0。因此 R>2，直接排除。

否则 0<rho0<1/2。只需考虑 R<2；R>=2 自动满足要证明的下界。
令 delta=2-R>0，x=delta/e>0，a=1-2rho0>0，A=1/2-k0-rho0。
保留盒子、初始查询、递归报告和编码四项，其余项全部丢弃：这只会
放松模型，所以由必要条件得到的下界仍适用于完整十二项模型。

盒子成本给出 S>=x。初始查询给出 b>=x-1/2+H(theta)。
递归成本和 S>=x 给出

  b <= B(x) = [A-(1+rho0)x]/a。

初始开关还给出 b>=(x-gamma_c(theta))/2。
将上述两个 b 的下界分别与 B(x) 比较，得到

  x <= [2A+a gamma_c(theta)]/3；
  x <= [1-2rho0-k0-a H(theta)]/(2-rho0)。

若 theta<=t0，第一式给出 x<=[2A+a*g0]/3；
若 theta>=t0，第二式给出 x<=[1-2rho0-k0-a*h0]/(2-rho0)。
因此整个连续 theta 区间都满足

  x <= U = max((2A+a*g0)/3,
               (1-2rho0-k0-a*h0)/(2-rho0))。

若 U<=0，与 x>0 矛盾，只可能有 R>=2。
否则检查器继续验证 C=aE0-A>0。编码项给出

  e(E0-b)+delta <=1，

从而（用 b<=B(x)）

  delta <= a*x/[C+(2-rho0)x]。

因 C>0，右侧对 x 严格递增。因此得到区间统一下界

  R >= 2-a*U/[C+(2-rho0)U]。

注意：没有假设成本项在最优点相等，没有假设局部优化器找到最优，
也没有把一组离散采样点当作全区间证明。

global_certificate.json 包含 182 个闭整数区间。verify_global.py
逐个验证其下界严格超过 1.960613492，并验证它们依次、无缺口、无重叠
覆盖 [3,231] 与 [233,2^26-1]，且不包含 232。

已经给定的 JSON 用标准库即可独立于优化器复验。

5. 无限尾部 c>=2^26

仍只需考虑 R<2。初始查询和 b<0、H(theta)>=0 给出

  x=(2-R)/e <=1/2+b-H(theta)<1/2。

编码成本给出 e(E_c-b)<=R-1<1，因此 e<1/E_c。
又 E_c = [log_2 c -(c-1)log_2(1-1/c)]/2 >= (log_2 c)/2。
当 c>=2^26 时 E_c>=13，于是

  2-R=e*x <1/(2E_c)<=1/26，
  R > 2-1/26 = 51/26 > 1.960613492。

这里被限制的是 x，不是 S；不能从初始查询推导 S<1/2。
这条解析证明处理无限尾部，所以不存在未检查的“大 c”。

6. 另一个局部排除：逐层精确熵不会救活当前参数

固定 v3 八次 c=232 的 e,b,S,tau，令 v=S-2b，取证书有理点 u。
设

  a_u=(gamma_232(u)-v)/(1+gamma_232(u))。

精确区间算术验证

  0 < a_u = 0.44442879439028534064... < tau=0.65。

任何满足相同盒子节省条件的精确连续阈值 t(a)，在 a=a_u 都必须满足
gamma(t(a_u)) >= (v+a_u)/(1-a_u)=gamma(u)，故 t(a_u)>=u。
在 t<=1/2 的范围内，H 单调递增，所以

  sup_{0<=a<=tau} (1-a)H(t(a))
    >= (1-a_u)H(u)
    = (1+v)H(u)/(1+gamma(u))。

相对于当前统一上界 rho*(1+v)，所能减少的递归指数小于

  0.000000000097794594 < 10^-10。

整数层网格在 n 趋于无穷时变密；由 gamma 和 H 的连续性，同一下界
适用于渐近主指数。开关舍入只会提高所需阈值，不会规避该限制。

本段只固定当前参数，不能误读为所有可能逐层调度的全域排除定理。
即使完全消去当前递归熵上界的这点误差，初始查询等其他瓶颈仍在。
