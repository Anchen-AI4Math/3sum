## 1. 记号与原成本结构

H 为以 2 为底的二元熵，连续定义 H(0)=H(1)=0：

    H(t) = [-t ln(t) -(1-t)ln(1-t)] / ln(2).

对固定整数 c>=3，定义

    E_c = (c/2) H(1/c),
    kappa_c = 2c H(1/(2c)) - c H(1/c) - 1,
    gamma_c(t) = c H(1/c) - c H((1-t)/c).

c=256 时，这正是上游 `Parameters.lean` 中的 E、kappa、gamma。
参数记为 epsilon=e>0、bandShift=beta=b<0、boxSaving=S>0、
initialTheta=theta、terminalFraction=tau、entropyRatio=rho。
令 v=S-2b>0。

保留上游十二项计费结构，其参数化形式为：

1. 2e E_c；
2. 1+e(E_c-b)；
3. 2-eS；
4. 2-e(1/2+b-H(theta))；
5. 2-e[1/2-b-kappa_c-rho(1+S-2b)]；
6. 2-e(tau-1/2-b-kappa_c)；
7. e(8/5)(E_c+1/2)；
8. 2+e(4/5-(2/5)E_c-2b)；
9. 1+e(1/2-b)；
10. 2-e(E_c+b)；
11. 2-2e(E_c+b)；
12. 1。

上游在 c=256 的固定参数上证明了这些计费项到程序预算的连接。本轮不把那个
固定参数定理误当成已经证明的任意参数/任意 c 的机器定理。第 6 节解释
c 变化所需的有限组合条件，SOURCES.md 标明仍需完整组合审计的部分。

## 2. 正系数展开：构造能精确计算的更强开关

### 引理 2.1（精确展开）

对 c>=3、0<=t<=1/2，有

    gamma_c(t)
      = log_2(c-1) t
        + (1/ln 2) sum_{j=2}^infinity
          [1+(-1)^j/(c-1)^(j-1)] t^j / [j(j-1)].

证明：gamma_c(0)=0，并且

    gamma_c'(t) = [ln(c-1+t)-ln(1-t)]/ln 2
                = [ln(c-1)+ln(1+t/(c-1))-ln(1-t)]/ln 2.

在 [0,1/2] 上两条对数级数一致绝对收敛。展开并逐项积分即得。
对于每个 j>=2，因 c-1>=2，括号中的系数严格为正。

### 推论 2.2（有限多项式下界）

任选次数 d>=2 和正有理数 a_1,...,a_d，满足

    a_1 <= log_2(c-1),
    a_j <= [1+(-1)^j/(c-1)^(j-1)]/[j(j-1)ln 2]   (j>=2).

则 P(t)=sum_{j=1}^d a_j t^j 满足 P<=gamma_c，且 P 在 [0,1/2] 上
严格递增、凸。由于系数为正，只需检验 P'(1/2)<9 就能保证整个区间
0<P'(t)<9。

这些系数上界不是通过采样得到：检查器用有理数对数区间逐一验证。
每个 JSON 的 numerators 和 denominator 给出了系数的完整精确值。

### 简单的 c=232 四次开关

    P_4(t) = 7.85174904 t + 0.72447023 t^2
           + 0.24044466 t^3 + 0.12022459 t^4.

所有小数都是分母 10^8 的有理数。与上一轮的三次开关相比，这里只增加
一个次数；它已经足以支持同一个 1.960614 目标。八次版本不是这个目标的
必要条件，只用于得到更紧的成本证书及模型夹逼。

## 3. 连续区间的统一熵证书：不是网格测试

### 引理 3.1（两条支撑线）

取有理 u in (0,1/2)。定义

    A=-log_2(1-u),  B=log_2((1-u)/u).

H 的凹性给出 H(t)<=A+Bt。P 的凸性给出

    P(t)>=P(u)+(t-u)P'(u).

给定有理 rho>0，令

    L(t)=rho[1+P(u)+(t-u)P'(u)]-(A+Bt).

L 是仿射函数。如果 L(0)>0 且 L(1/2)>0，则对整个 [0,1/2] 有

    H(t)<rho[1+P(t)].

证明只需把两个支撑线不等式合起来；仿射函数在两个端点的严格正性
通过线性插值覆盖整个闭区间。熵的端点由连续延拓处理。

### c=232 四次证书的具体见证

    rho = 0.27905030,
    u = 0.17200068185091493.

精确区间检查得到

    L(0)   > 0.000000001486795215,
    L(1/2) > 0.000000007676481609.

因此这条统一不等式对每一层、每个可能的阈值都成立，而非只对有限个点成立。

c=232 八次证书采用 rho=0.27904885505；c=256 八次证书采用
rho=0.27620057697。它们的有理切点与端点裕量都在 JSON 与验证输出中。

## 4. 有限整数调度：从证书到可执行比较

### 4.1 分块与分带

给定输入规模 n，m=floor(log_2 n)。取原来的偶数微块尺寸

    s=2 floor(floor(m^(1/3))/2).

对 s>0，设

    J=20 floor(e m/(20s)),   mu=Js.

于是 20|J 且

    0 <= e m-mu <20s.

由于 s=Theta(m^(1/3))，有 mu/m -> e。
对 s=0 或 J=0 的有限异常规模，保留穷举分支。

新的 band 分母为

    2^floor(-b mu).

它和理想值 2^(-b mu) 相差不到因子 2，不必为了参数分母让 mu 具有额外
巨大整除性。tau=13/20，因此原有 20|J 足够保证终止层为整数。

### 4.2 多项式开关的精确整数实现

写 P(t)=sum a_i t^i/Q，a_i 为 JSON 中的正整数，v=N/D。
在第 j 层，a=j/J，残余大小 r=(J-j)s，选择最小整数 q in [0,r/2]，使

    D(J-j) sum_{i=1}^d a_i q^i r^(d-i)
      >= Q(NJ+Dj) r^d.                                  (I)

清除正分母后，(I) 恰好等价于

    P(q/r)>=(v+a)/(1-a).

没有对数或浮点指令。次数 d、系数、N、D、Q 都是固定常量；可以用固定
次数乘加和对数规模的整数搜索计算。即使线性枚举 q，也只有 O(mu) 次，
为输入规模的多对数开销。这个事实不提供实际耗时或常数优越性的证明。

### 4.3 对所有层保证存在、盒子界和查询界

检查器验证

    P(1/2) > (v+tau)/(1-tau).

因为右侧是层数 a 的递增函数，所有 0<=a<=tau 都有合法 q。v>0 保证
q>=1。q 的最小性和 0<P'<9 给出

    threshold <= P(q/r) < threshold+9/r.

令 t=q/r，有

    S <= 2b-a+(1-a)gamma_c(t),

以及由引理 3.1

    (1-a)H(t) < rho(1+v)+9rho/mu.

这恰好是原开关分析需要的盒子节省和递归查询熵形式，舍入项与层数无关。

初始层另验证 P(theta)>v。取 ceil(theta*mu) 就能保证可行，故实际初始
阈值不超过 theta+1/mu。H 在 theta 处的上切线进一步给出

    H(t_initial) <= H(theta)+H'(theta)/mu.

因此初始查询也有有限舍入控制，不需要把一个实数阈值当成可执行指令。

上述是一般证明；脚本附带 2619 个小规模清分母检查只是防止实现抄写错误，
不被用来代替这个对所有层成立的论证。

## 6. c=232 的有限组合依据及继承边界

上游 LocalCoverBounds.lean 中的以下关键命题是关于一般 L,h 的，不是只对
512h 才成立。设微块 s=2h，L=cs，定义

    M=binom(L,s), V=binom(L,h),
    Delta=binom(L-h,h), G=binom(s,h).

通过“先选左端点再选右端点”与“先选并集再划分”的双计数，

    V Delta = M G.

又有 Delta<=V、G<2^s。故 Delta^2< M 2^s。
通过从 s 个互不相交的 c 元集合各选一元素的单射，

    M>=c^s>2^s  (c>2, s>0).

选择位于 ceil(sqrt(M2^s)) 之上、两倍该整数以内的素数 p，得到

    M2^s <= p^2 <=16 M2^s.

于是 Delta<p、G<p，并保留原独立桶裁剪的分母和均值估计。
这些有限事实不会要求 c 是 2 的幂。

标准二项式熵估计给出

    log_2 M = c H(1/c)s + O(log s),
    log_2 V = c H(1/(2c))s + O(log s),
    log_2 p = (E_c+1/2)s + O(log s).

因此局部桶重数的平方在指数上给出 kappa_c。
固定 c 后，局部穷举仍有 2^{O(s^2)} 开销，且
s^2/m ->0；跨 J 个微块的多项式因子满足
J log(s)/m ->0，所以这些因素仍是 n^{o(1)}。

这些说明为什么把局部扩张从 256 换成 232 具有同构的有限组合基础。
但是原源码仍有写死的维数和成本常量：本轮没有逐条重新组合全部调用的
运行时间合同。因此包内证书的严格声明仍是“解析及参数化成本证书”，而非
已经完成的 EndStatement.ThreeSum.SolvedInTime 机器定理。

## 7. 固定成本模型的下界证书：不再只是数值最优化

### 7.1 定义比较的模型

固定 c，使用精确 E_c、kappa_c、gamma_c、H。允许任意满足以下条件的参数：

- 0<e<1，b<0，S>0，0<=theta<=1/2；
- v=S-2b>0，gamma_c(theta)>=v；
- rho>=rho_c^*，其中 rho_c^*=max_{0<=t<=1/2} H(t)/(1+gamma_c(t))；
- 其余 band、终止、读入和外围条件与十二项成本表一致。

目标 R 是十二项成本的最大值。允许精确 gamma 的这个模型比只能用四次或
八次下界的模型更宽松。后面为了证明下界，还会丢掉八项成本和终止条件。
因此得到的是一个确实适用于整个上述固定-c模型的下界。

### 7.2 只留四项，使用有利于算法的放松

取已经证明的下界 E0<=E_c、k0<=kappa_c、rho0<=rho_c^*，其中
0<rho0<1/2。rho0 用一个有理点 u 的值

    H(u)/(1+gamma_c(u))

作下界见证，不需要求出函数的精确最大值。因为 1+v>0，把 rho、kappa、E
都向这个方向替换只会降低相关成本。

假设一个容许方案达到 R<2。令

    delta=2-R>0, x=delta/e>0,
    a=1-2rho0>0, A=1/2-k0-rho0.

盒子成本迫使 S>=x；初始查询成本迫使

    b>=x-1/2+H(theta).

递归报告成本及 S>=x 迫使

    b <= B(x) := [A-(1+rho0)x]/a.                         (B)

初始开关和 S>=x 又给出

    b>=(x-gamma_c(theta))/2.

分别与 (B) 组合，可得两个必要条件

    x <= [2A+a gamma_c(theta)]/3                 := U_G(theta),
    x <= [1-2rho0-k0-a H(theta)]/(2-rho0)        := U_H(theta).

U_G 递增，U_H 递减，因为 gamma_c、H 在 [0,1/2] 上递增。
因此任选一个有理分割点 t0，就能覆盖整个 theta 区间：

    theta<=t0  => x<=U_G(t0),
    theta>=t0  => x<=U_H(t0).

所以对所有 theta 有

    x <= U := max(U_G(t0),U_H(t0)).

实际检查用 gamma_c(t0) 的上界、H(t0) 的下界，故 U 是安全有理上界。

### 7.3 编码成本把 x 的上界转为 R 的下界

编码成本要求

    e(E0-b)+delta <=1.

应用 b<=B(x) 和 delta=ex，得到

    delta <= a x/[a E0-A+(2-rho0)x].

检查器明确验证 C=aE0-A>0。因此右侧关于 x 严格递增，代入 x<=U 可得

    R >= 2 - a U/[C+(2-rho0)U].                          (LB)

整个证明没有假设四项必须同时取到最大，没有假设数值优化器找到全局最优，
也没有对 theta 做网格抽样。(LB) 是由必要条件推导的全域下界。

### 7.4 本次的有理见证与结果

c=232 使用

    t0 = 0.04040989819170768,
    rho0 = 0.279048854686216,
    E0 = 4.648781151243719,
    k0 = 0.001557987216578.

检查器对 (LB) 得到

    R_model(232) >= 1.960613491206699282734...
                 > 1.96061349120.

结合八次可行证书，得到

    1.96061349120 < inf R_model(232) < 1.960613492.

区间宽度为 8*10^-10。这个结论支持“继续只调这些参数的空间很小”，不支持
“3SUM 不可能更快”。换一个算法、改掉编码或报告成本、使用不同递归估计，
或者更换/混合 c，都不由这条固定模型下界排除。

同理 c=256 的模型得到

    R_model(256) >= 1.960620300023327565768...
    1.96062030002 < inf R_model(256) < 1.960620301.

本包没有宣称 c=232 在所有 c 上全局最优。可选 explore.py 的 c 搜索只是
用于找到见证；任何数值探索结果都不参与这些证书的真假判定。

## 8. 复验器的可信边界

运行

    python verify_certificate.py --self-test

只用 Python 标准库。所有 PASS/FAIL 都使用 Fraction 有理运算，不使用浮点。
对数先用 2 的幂约化到 [1,2]，写 z=(x-1)/(x+1)，因此 0<=z<=1/3。

    ln x = 2 sum_{i=0}^{K-1} z^(2i+1)/(2i+1) + remainder,
    0<=remainder<=2 z^(2K+1)/[(2K+1)(1-z^2)].

这里 K=48。负的范围约化指数通过区间运算处理，不会把上、下界颠倒。
显示的小数向外舍入；显示精度与证明精度是两回事。

检查器验证的内容为：

- 全部多项式系数、全区间熵支撑线、单调性/凸性/导数所需数值条件；
- E、kappa、初始熵的有理上下界及所有调度侧条件；
- 十二项成本（含符号方向）及目标余量；
- 第 7 节下界证明所需全部有理见证；
- 有限组合/整数调度的防抄写错误测试。

另有四种故意损坏的证书必须被拒绝：错误 rho、放大多项式系数、过低的成本
上界、过高的模型下界。每份证书都实际运行了这些负向测试。

这不是 Lean 或另一种形式逻辑内核；对连续引理的逻辑桥接依赖本文件给出的
数学证明，解释器与检查器自身也属于可信计算基础。证书算术通过，不会自动
认证作者身份、新颖性、实际运行速度或完整机器复杂度。
