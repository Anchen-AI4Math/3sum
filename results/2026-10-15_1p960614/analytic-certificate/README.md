# 3SUM 1.960614：v3 证书包

本包继续分析 c0ldzy17 的确定性 word-RAM 3SUM 路线。
**先做数学证书，不包含 Lean 源码或编译任务。**

## 已完成

1. 正系数级数产生的有理多项式开关；四次已足够支持 1.960614。
2. 通过支撑线端点比较证明的全区间熵界，而不是网格采样。
3. 三组可行参数及全部十二项成本的精确有理区间验证。
4. 对所有规模/层数的整数调度论证，并附有限防抄写错误测试。
5. 固定 c=232 的理想化成本模型最优值夹逼：

       1.96061349120 < inf R_model(232) < 1.960613492.

   不是 3SUM 下界，也不覆盖不同算法/其他 c 的全局最优性。

## 一条命令复验

需要 Python 3.10 或更新版本；核心检查只用标准库。

```sh
python verify_certificate.py --self-test
```

默认依次检查 c=256 八次、c=232 四次、c=232 八次三份证书；每份还会拒绝
四种故意损坏的证书。通过时最后输出 `ALL REQUESTED CERTIFICATES PASSED.`

也可只检查最简单的新目标：

```sh
python verify_certificate.py certificates/c232_quartic.json --self-test
```

## 文件

- `PROOF.md`：数学证明、参数、整数调度、模型下界的完整推导与范围。
- `certificates/c232_quartic.json`：简单四次开关，主成本 <1.96061388，目标1.960614。
- `certificates/c232.json`：八次精化，主成本 <1.960613492，目标1.960614。

- `verify_certificate.py` / `exact_interval.py`：独立于优化器的有理数复验器。
- `verification_output.txt`：本次真实执行的完整输出。
- `summary.json`：各阶段安全上界及模型下界。
- `explore.py`：可选浮点探索；需要 SciPy，**不参与证书验收**。

- `SHA256SUMS.txt`：包内文件校验值。

到实际机器运行时间的组合没有由本检查器认证，不能把1.960614记作平台已
验证纪录。**数学证明不必依赖Lean，但这一组合仍需纸面或其他可靠审计。

本轮没有提交/发布外部平台，也没有测量实际性能、常数或交叉规模。
原算法与形式化基础的署名保留上游 METHOD.md / NOTICE 的归属。
